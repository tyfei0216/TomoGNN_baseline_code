# Compare Release 

This repository contains release-ready baselines and evaluation notebooks 

## Folder Overview

- `deepETpicker/`: Particle picking notebooks for DeepETPicker experiments and assessment.
- `deepict/`: Particle picking notebooks, result CSVs, and post-processing/tuning outputs for DeepICT.
- `SAM2/`: Segmentation baseline code (`dataset.py`, `train_eval.py`) and release notebook for SAM2.
- `Unet/`: Segmentation baseline code (`dataset.py`, `model.py`, `train_eval.py`) and release notebook for U-Net.
- `srcs/`: Shared utility code used by experiment and evaluation workflows.

## Release Notes

- Intended for reproducible baseline comparison across particle picking and segmentation pipelines.
